# Agent Instructions

These instructions apply to the entire repository.

## Source of truth

- Treat this repository as the only editable source of the Typora extension.
- Typora does not dynamically load files from this directory.
- Never patch files inside `/Applications/Typora.app` directly. Edit the repository, test it, and use `scripts/install.sh`.
- The installed JS/CSS, helper, LaunchAgent, and skill are copies generated by the installer.

## Annotation safety

- User annotations live under `~/Documents/typora`, outside this repository.
- Do not delete or rewrite annotation JSON for UI, rendering, anchoring, installation, or test work.
- Preserve the `quote`, `prefix`, and `suffix` anchor contract.
- Only resolve an annotation when the user explicitly asks to change its status; do not silently delete annotations.

## Required workflow

1. Inspect the relevant source and existing tests before editing.
2. Make source changes in this repository, preserving unrelated user work.
3. Run all checks:

   ```bash
   node --check typora-annotations.js
   node test/annotations.test.js
   /usr/bin/python3 test/storage.test.py
   ```

4. Add a regression test for anchoring, geometry, or storage bugs when practical.
5. Install only when the user has asked for the change to be applied to Typora:

   ```bash
   ./scripts/install.sh /Applications/Typora.app
   ```

6. Verify the installed copies and runtime:

   ```bash
   cmp -s typora-annotations.js /Applications/Typora.app/Contents/Resources/TypeMark/typora-annotations.js
   cmp -s typora-annotations.css /Applications/Typora.app/Contents/Resources/TypeMark/typora-annotations.css
   codesign --verify --deep --strict /Applications/Typora.app
   curl -s http://127.0.0.1:17373/v1/health
   ```

7. Tell the user to save their documents and restart Typora. A running Typora process continues using the previously loaded extension.

## File map

- `typora-annotations.js`: injected editor behavior and annotation rendering.
- `typora-annotations.css`: annotation and sidebar presentation.
- `tools/typora_annotations.py`: storage CLI and localhost helper.
- `scripts/install.sh`: stages, injects, signs, and replaces the app while preserving the original backup.
- `scripts/install-support.sh`: installs the helper, LaunchAgent, and global skill.
- `scripts/uninstall.sh`: restores the original app without deleting annotation data.
- `test/`: JavaScript anchoring/geometry tests and Python storage tests.
- `skill/typora-annotations/`: instructions installed for agents that process user annotations.

## Git hygiene

- Do not commit generated caches, installed app contents, backups, or user annotation data.
- Keep commits focused and include the relevant test result in the handoff.
- Do not amend, reset, or discard user changes unless explicitly requested.
